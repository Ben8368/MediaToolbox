# Frontend UI Compatibility Baseline

本文档记录 MediaToolbox 前端的 UI 兼容原则。目标是保留用户熟悉的 NAS 风格桌面布局、视觉节奏和操作路径，并在真实后端接入阶段继续保持体验一致。

## 1. 当前结论

- 本仓库为桌面应用 monorepo；前端通过本地 API 使用生产能力。
- 技术栈：React 18 + TypeScript + Vite + Zustand；Node >= 22。
- 首屏是 NAS 风格 Web 桌面体验。
- 跨源调试时，`VITE_API_BASE_URL` 指向本地 API 服务。

## 2. 兼容原则

- **布局优先兼容**：左侧状态栏、桌面区、多窗口、启动器、右侧状态面板等空间关系保持稳定。
- **App 左侧栏规范**：工作台左侧栏默认宽度统一为 `200px`，通过 `ResizableAppSidebar` 提供 `160–360px` 拖拽/键盘调整、双击恢复默认值和按 App 持久化；新 App 不得另行硬编码左侧栏默认宽度。
- **用户路径优先**：下载器、文件管理器、设置、日志等高频入口要延续来源项目的使用记忆。
- **业务逻辑不进前端**：前端只负责参数填写、任务展示、状态呈现和结果入口。
- **真实 API 默认**：组件通过 `@/api` 访问能力，历史 `mockApi/` 仅作为迁移参考或测试夹具。
- **渐进恢复**：先打磨最高频工作流，再恢复复杂能力。

## 3. 当前前端范围

已包含：
- 桌面壁纸和静态图标资产
- 左侧状态栏
- 桌面图标
- 应用启动器
- 多窗口容器
- 右侧状态面板
- 下载器 UI
- 文件管理器 UI
- 转码工作台
- PSD 工作台核心闭环（检查入口、manifest 编辑、文字 slot 渲染提交、批量渲染结果展示、manifest 保存/加载）
- Web Composer 工作台 beta（锁定预设、Slot 文案编辑、图片/视频替换、颜色和字体变量、比例/分辨率设置、PNG/MP4 导出）
- 浏览器 app 多标签页前端 UI
- 右侧状态面板真实系统指标展示（CPU / 内存 / GPU；macOS Apple Silicon 已验收，可用性不足时显示可读降级）
- 设置入口
- 日志入口

仍待验收或补齐：
- 浏览器 app 桌面端多标签页真机体验（view 生命周期、隐藏旧 view、下载归属和权限提示）
- Electron 完整安装包发布体验（签名、公证、跨平台安装包验收；基础生产打包链路已接入）
- PSD 真实 Photoshop 本机联调、image / smart-object slot 渲染和复杂 batchPlay
- 更完整的项目上传流量采集（非浏览器请求体场景）
- Web Composer 默认远程预设素材与 4K/长时 MP4 的桌面端压力验收

## 4. 验收标准

- 用户能沿用来源项目的主要视觉记忆找到功能入口。
- 下载、文件管理、浏览器、转码、PSD、Web Composer 与设置工作台的左侧栏默认为 `200px`；调整后内容区实时重排，切换或重新打开 App 后保留各自宽度，窄屏隐藏规则不回归。
- 前端没有把未接入能力伪装成真实后端能力。
- 下载器和文件管理器的错误、空态、加载态可读。
- Web Composer 通过统一 `appRegistry` 启动，并继承全局 `960×640` 默认窗口和 `760×520` 最小窗口；最小窗口下属性区可独立滚动，预设画布保持可见。
- 预设只允许修改声明的 slot 和样式变量；预设结构、样式与动画的完整性锁测试必须通过。
- `npm run verify` 通过（= test + typecheck + build）。
- 主观体验通过用户确认后，才能将相关 Feature 标为完成。
