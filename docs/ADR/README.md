# Architecture Decision Records

ADR 用于记录已经影响长期维护的架构决策。路线图说明“做什么”，ADR 说明“为什么这样做”。

## 格式

每条 ADR 使用短编号：

```text
docs/ADR/0001-title.md
```

建议结构：

- 状态：提议 / 已接受 / 已替代
- 日期
- 背景
- 决策
- 后果
- 关联文档
