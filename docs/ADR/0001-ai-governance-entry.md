# ADR 0001: AI 协作入口与红绿灯验证闭环

- 状态：已接受
- 日期：2026-07-07

## 背景

MediaToolbox 是 AI 高频参与开发的 TypeScript monorepo。若每个工具各自维护规则，容易出现状态漂移、假成功、mock 冒充真实能力和文档失真。

## 决策

- `AGENTS.md` 作为通用 AI 治理入口和权威规则源。
- 工具专属入口只做摘要，例如 `CLAUDE.md`。
- 每轮先读 `CONTEXT.md` 和 `LESSONS.md`，再按需读取架构、API、UI、路线图等专题文档。
- 代码改动后先输出 `🚦 Audit Report`，再运行客观验证。
- 默认客观验证为 `npm run verify`。
- 阶段、功能、用户命令、API 契约或架构边界变化时，同步更新上下文或相关文档。

## 后果

好处：

- AI 工具共享同一个治理事实源。
- 状态、验证和提交规则形成闭环。
- 可以更早暴露假完成、硬编码和安全边界破坏。

代价：

- 文档维护成本更高。
- 自动提交规则需要随着协作规模扩大继续收紧。
